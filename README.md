# Política de Privacidade — Capivara Coins

Este repositório existe por um motivo só: hospedar, numa URL pública e estável,
a política de privacidade exigida pelo Google Play para o aplicativo
`com.steelrabbit.capivacoins`.

A página é `index.html`, servida pelo GitHub Pages.

**A fonte do texto é o repositório do jogo**, em `docs/politica-privacidade.md`.
Este repositório só carrega a versão publicada. Ao mudar a política lá, gerar a
página de novo e enviar aqui — nunca editar o texto direto no HTML, porque aí as
duas versões passam a discordar e a que vale juridicamente é a que está no ar.
